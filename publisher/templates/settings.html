How to restore a backup

Backups are in the backups folder next to docker-compose.yml on the server: one .dump file (the database) and one .keys.tgz file (the key that opens saved passwords) per backup. Copy that folder somewhere else now and then: a backup on the same disk does not survive a broken disk.

To go back to a backup (everything after it is lost), on the server:

cd ~/Ardea
sudo ./backup/restore.sh backups/ardea-2026-11-20_0200.dump
